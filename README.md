# Quina_valleys

## Layout

- `scripts/` — all R analysis scripts (`00_setup.R` ... `04_geology_map.R`, `QV_*.R`, `Quina_scraper_statistic.R`).
- `data/` — source spreadsheets/CSVs (`Site_information.xlsx`, `Quina_scraper_surface.xlsx`, `Longtan_lithic_tools.xlsx`, `Raw_mat_basin.xlsx`, `Quina_sites_27_clean.csv`) and `data/cache/` for downloaded/derived spatial data (DEM, rivers, admin boundaries — regenerated by `00_setup.R` / `00b_rivers_from_dem.R`).
- `output/` — figures and tables generated by the scripts (gitignored; regenerate by re-running the scripts).
- `paper/` — manuscript (`manuscript.qmd`, `references.bib`).
- `templates/` — Quarto/Pandoc templates and reference files used by the manuscript (`template.docx`, `.lua` filters, `.csl` style).

Run order: `scripts/00_setup.R` -> `scripts/01_map.R` -> `scripts/02_spatial_stats.R` -> ... (see header comments in each script).
